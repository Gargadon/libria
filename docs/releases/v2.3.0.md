Libria 2.3.0 — Borges Edition

## Dictado por voz sin conexión

- Nuevo botón de grabación en la barra del editor para escribir con la voz usando Vosk.
- Modelos pequeños incluidos para español, inglés, francés, italiano, alemán y portugués. Se utiliza el idioma del libro, independiente del idioma de la interfaz.
- El motor y los modelos se preparan al empaquetar: el dictado funciona sin Internet desde el primer inicio y el audio se procesa en el equipo.
- Las frases confirmadas se insertan en el cursor; el texto provisional se muestra aparte. Al detener, se procesa la última frase. El texto se puede corregir y deshacer en el editor.
- Al cambiar de capítulo o comenzar a editar, se cancela el dictado pendiente. El micrófono y la memoria del modelo se liberan al terminar.

## Correcciones del editor

- Corregido el fallo que dejaba vacío el párrafo siguiente después de cortar un párrafo con Ctrl+X y pulsar Backspace.
- Corregida la actualización del texto visible al deshacer una edición con la selección activa.

## Instalación y empaquetado

- Los instaladores incluyen los seis modelos de dictado; solo se carga en memoria el correspondiente al idioma del libro.
- En Linux se prefiere una biblioteca Vosk compatible del sistema. El paquete de Arch declara vosk-api y se proporciona una configuración RPM para usar vosk-api-devel.
- Windows ARM64 utiliza un auxiliar x64 para ejecutar el motor Vosk oficial mediante la compatibilidad de Windows.
- El workflow verifica los recursos locales de dictado antes de publicar los instaladores y obtiene el nombre de edición desde package.json.
- Actualizado el libro de ejemplo El Principito.

El nombre Borges Edition acompaña la incorporación del dictado como una nueva forma de escribir y revisar en Libria.
